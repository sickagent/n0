# sickagent profile site

Минималистичный статический сайт профиля с отдельной SEO-страницей проекта n0.

Файлы можно развернуть на GitHub Pages, Netlify или любом статическом хостинге. Для GitHub Pages замените URL в `robots.txt` и `sitemap.xml`, если сайт будет размещён не на `sickagent.github.io`.
